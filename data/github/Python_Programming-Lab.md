## Labs Overview

| Lab | Topic | Contents |
|:---:|-------|----------|
| **1** | Basics of `print()` | Patterns, newline handling |
| **2** | Variables & Data Types | Assignment, dynamic typing, scope, `input()` / `print()` parameters |
| **3** | Input, Output & Operators | 45 standalone programs — arithmetic, formatting, applications |

## Getting Started

Clone the repository and move into the project folder:

```sh
git clone https://github.com/Manas-Dikshit/Python_Programming-Lab.git
cd Python_Programming-Lab
```

### Running the Programs

Every script is standalone. Run any of them with:

```sh
# Windows (Python 3)
python lab1\assignment1.py
python lab3\program01.py

# Linux / macOS
python3 lab1/assignment1.py
python3 lab3/program10.py
```

> **Note:** Most Lab 3 programs accept input via `input()` — run them in a terminal and follow the prompts.

### Documentation

Open the Lab 2 documentation:

```sh
start lab2\Lab2.docx     # Windows
open lab2/Lab2.docx      # macOS
xdg-open lab2/Lab2.docx  # Linux
```
